# Security policy

MicroCard 0.1-wip is development firmware and does not yet receive production security support.

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature for `mistial-dev/MicroCard`. Do not include private keys, credentials, personal data, or restricted standards documents in a report.

The security boundary and current hardware limits are documented in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/READINESS.md](docs/READINESS.md).
