# MicroCard analyzers

Roslyn diagnostics for the C# subset that MicroCard can preprocess into an embedded assembly. Install this package as a development dependency. The same restrictions must still be enforced by preprocessing and by the device verifier.
`MCA0001` through `MCA0023` are enabled by default at error severity. They cover unsupported language features and types, including async methods, using declarations, `init` accessors and `typeof` runtime type inspection, declaration shapes including interface implementation, static constructors, event declarations, by-reference returns and auto-properties with unsupported backing storage, external calls, assembly lifecycle metadata, dependency export/import policy, transaction safety, recursion, managed call depth, the 64-local and 32-parameter per-method limits, the 16-dependency, four-entry-point, 256-method, 253-TypeDef, 1,022-FieldDef and 256-runtime-attribute assembly limits, constant array allocations that cannot fit the 16 KiB arena, repeated array, collection-expression, or object allocation inside loops, aggregate statically sized allocations within one method or through unconditional same-assembly calls, statement or expression switches above the 256-target MC04 limit, and unconditional call paths above the 256-object table. The exact `System.Security.Cryptography.SHA256.HashData(byte[])` and `System.Security.Cryptography.RandomNumberGenerator.GetBytes(int)` platform calls are allowed and securely projected to the pinned framework during preprocessing; every other member on those types remains an external-call error. The TypeDef ceiling includes the required module row. Int32 constants are embedded in CIL and do not consume FieldDef rows. Array estimates include the runtime's 16-byte header; sealed objects use the fixed 16-byte header and 16 bytes per field. Conditional allocations and calls remain subject to the authoritative runtime bounds without an aggregate edit-time error. An editor suppression or severity override never authorizes an assembly.
